# GKPay — Payment Gateway System

A production-style Payment Gateway built using Spring Boot Microservices, inspired by systems like Stripe and Razorpay.

GKPay is designed to demonstrate how real-world payment systems evolve — from a simple flow to a scalable, fault-tolerant architecture.

🎯 What is GKPay?

GKPay is a backend payment gateway that allows client applications to:

Initiate payments
Process transactions via an external provider (simulated)
Track payment status

This project focuses on system design + backend engineering, not UI.
